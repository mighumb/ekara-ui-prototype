# Ekara — Product context

## Ekara

Ekara by ip-label is a Digital Experience Monitoring platform.

## This repository

Interactive HTML/CSS/JS UI prototype of the Ekara interface
(layout, component behaviour, UX flows; handoff to engineering).
Styles: `tokens.css`, `ekara.css`. Preview from `main` via GitHub Pages.

## Product shell

- **Header** — logo, breadcrumb (`Module | Section > Page`), account, notifications, avatar, module switcher (9-dot bento)
- **Sidebar** — navigation for the active module (changes with the module)
- **Main content** — the active page

UI copy: English. Collaboration: French.

## Modules

Access: header → 9-dot grid.

1. Measures
2. Infrastructure
3. Settings
4. Management
5. Ekara Green
6. Incident Guard

Built screens: see `docs/prototype-coverage.md`.
Use the matching module shell (breadcrumb + sidebar) for each screen.
